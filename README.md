# 数字货币分析系统

这是一个用于分析数字货币市场数据的系统，提供价格走势、交易量分析和市场情绪指标等功能。

## 系统架构

系统由以下几个主要模块组成：

1. **数据采集模块**：从各大交易所API获取数字货币的实时和历史数据
2. **数据存储模块**：将采集的数据存储在本地数据库中
3. **分析引擎**：对数据进行处理和分析，计算各种技术指标
4. **用户界面**：以可视化方式展示分析结果

## 安装与使用

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行系统

```bash
python main.py
```

## 功能特点

- 多币种数据分析
- 实时价格监控
- 技术指标计算（如MA、RSI、MACD等）
- 市场情绪分析
- 数据可视化展示
